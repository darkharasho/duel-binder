# Pokédex Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Pokémon-only Pokédex page (desktop, phone, web): a grid of all 1025 species with sprites, caught when
you own any card of that species, with a progress bar and a per-species panel of owned and missing cards.

**Architecture:** The nightly catalog build stores each Pokémon card's National Dex number(s) in two new
`pokemon_cards` columns (`dex_no`, indexed; `dex_extra` for multi-Pokémon cards), synced to every client by
the existing catalog feed. Two new data channels (`pokedex:summary`, `pokedex:species`) run the same
`src/main/repo/pokedex.ts` queries on desktop SQLite, the phone's wasm SQLite and the Worker's DO. Sprites
are PNGs in R2 under `sprite/<n>.png`, served by the Worker at `/img/sprite/<n>` (anonymous, year-long cache)
and by the desktop's `ygo-img://sprite/<n>` cache.

**Tech Stack:** TypeScript, React + Tailwind (renderer/phone), better-sqlite3 / DO SQLite, Cloudflare Worker +
R2, vitest (`npm test` already passes `--maxWorkers=2`).

**Spec:** `docs/superpowers/specs/2026-11-07-pokedex-design.md`

## Global Constraints

- Pokémon game (`'pkm'`) only; the page is hidden for Yu-Gi-Oh! and One Piece via `features.pokedex`.
- 1025 species, National Dex order; forms and Megas count toward the base species (TCGdex `dexId` already
  gives the base number).
- Caught = at least one live entry (`deleted_at IS NULL`, quantity > 0) of a card whose species list holds it.
  Trainer and Energy cards (`category <> 'Pokemon'`) never count.
- A card with several Pokémon (Tag Team) counts for each.
- Panel unit is a card (`cards` row), not a printing variant.
- Missing lists English cards of the species not owned; if the species has no English card, cards in any
  language. Panel subtitle: "you have X cards · N missing".
- Sprites: PokeAPI `sprites/pokemon/versions/generation-v/black-white/<n>.png`, 96×96, rendered
  `image-rendering: pixelated`; caught in colour, missing as a black silhouette (`filter: brightness(0)`,
  reduced opacity). Credit line: "Sprites: PokeAPI and the sprite artists credited there."
- Ships to everyone at once, no tester gate.
- Worker deploys are one-way: schema steps append only, never edit a shipped step.
- DO SQLite rejects big compound UNIONs: one simple query per lookup in the repo.
- Never build 100k+ row synthetic test data; small fixtures only.

## Review Focus

1. A species with no card at all in the catalog (newest Pokémon, no TCG card yet) → tile stays missing, the
   panel says "No cards of <name> yet" with no error. (Task 4 test `species with no cards`, Task 6 test.)
2. Signed-out desktop and unsigned iOS requests → sprites still load (route is anonymous; desktop source
   sends no auth header when signed out). (Task 5 tests.)
3. A collection of only Japanese / Chinese cards → species caught, panel "Yours" lists them, "Missing" lists
   English cards. (Task 4 test.)
4. Removing the last copy → the tile goes back to missing without a restart (pokedex queries invalidated
   with the collection's). (Task 6 test.)
5. A Trainer named after a Pokémon, or a TCGdex `dexId` of 0 / > 1025 → never counted. (Task 3 test.)

- Produces:
  ```ts

    cardId: number
    lang: PkmLang
    category: string | undefined
    dexId: number[] | undefined   // TCGdex's, as fetched
    name: string                  // the card's English name (CardPlan.name)
    twinIds: number[]             // artTwinId then traditionalTwinId, nulls dropped
  }
  ```

  Rules, in order:
  1. `category !== 'Pokemon'` → no entry.
  2. Numbers outside `1..POKEDEX_SIZE` are dropped.
  3. Name map: from `en` inputs with exactly one `dexId`, normalised English name → species; a name that maps

  4. `en` and European languages: their `dexId`.
  5. `ja` and `zh-hant` with exactly one `dexId`: the name map's species when it has one and it differs
     (TCGdex's Japanese `dexId` is wrong now and then); otherwise their `dexId`.
  6. No `dexId` (zh-hans, TCGplayer-only cards): the first twin that resolved, else the name map, else none.

**Interfaces:**
- Consumes: Task 2 columns; `Scope`/`LOCAL` (`src/main/repo/scope.ts`).
- Produces:
  ```ts
  export interface PokedexSummary { caught: { dexNo: number; copies: number }[] }
  export interface PokedexCard {
    cardId: number; imageId: number; name: string; setName: string; language: Language
    copies: number            // 0 in `missing`
  }
  export interface PokedexSpecies { dexNo: number; owned: PokedexCard[]; missing: PokedexCard[] }
  export function pokedexSummary(db: SqlDb, scope?: Scope): PokedexSummary
  export function pokedexSpecies(db: SqlDb, dexNo: number, scope?: Scope): PokedexSpecies
  // Api: pokedex: { summary(): Promise<PokedexSummary>; species(dexNo: number): Promise<PokedexSpecies> }
  // channels 'pokedex:summary', 'pokedex:species'
  ```
  `pokedexSummary`: owned entries joined to `card_printings` → `pokemon_cards`, grouped by `dex_no, dex_extra`,
  expanded in JS (each species in `dex_extra` gets the copies too), sorted by `dexNo`. Empty for a non-`'pkm'` scope.
  `pokedexSpecies`: two card-id lookups (`dex_no = ?`, then the `dex_extra IS NOT NULL` rows whose list holds
  it) — separate queries, no UNION; owned = cards with a live entry (copies summed over all printings),
  any language, newest set first; missing = English cards (a printing with `language = 'en'`) not owned,
  newest set first, or every language when the species has no English card. Handler validates `dexNo` as a
  whole number in `1..POKEDEX_SIZE` (`wholeNumber` in dataHandlers).

# Reverse Holo Detection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On the desktop scanner, name an English Delta Reign card Normal or Reverse Holofoil from the
frame it was scanned on, with no `check-rarity` flag.

**Architecture:** A shared function measures the body/art brightness ratio and body spread of an
upright card image. The vision worker measures the photo. A generated JSON in the repo holds the
same two numbers for each checked set's reference images. `resolvePokemon` applies the rule to a
named, non-guess English card whose only versions are Normal and Reverse Holofoil. The desktop scan
loop passes the reference lookup in; the phone doesn't, so it keeps today's behaviour.

**Tech Stack:** TypeScript, Electron renderer + vision worker, vitest, better-sqlite3 (script),
jpeg-js.

**Spec:** `docs/superpowers/specs/2026-11-10-reverse-holo-detection-design.md`

**Deviation from the spec (my call, flagged to the owner):** the spec puts reference stats in the
nightly fingerprint build. Once checked sets were added, only checked sets need stats (about 141
Delta Reign images). So this plan ships them as a JSON file generated by a script and committed
with the PR that checks the set. There is no nightly change, no portal endpoint, and no Worker
deploy. Each set-adding PR already exists by design, so it regenerates the file.

## Global Constraints

- Regions, as fractions of the upright card: ART = x 0.06–0.94, y 0.09–0.47. BODY = x 0.05–0.95,
  y 0.54–0.86.
- Every image, photo and reference alike, is shrunk to 200x292 by area averaging before measuring.
  A reference with alpha is flattened on white first.
- Luma = 0.299 R + 0.587 G + 0.114 B.
- Rule: Reverse Holofoil if bodyLum < 0.69 or spread > 0.20, else Normal. Thresholds live in
  `src/shared/scan/thresholds.ts` as `REVERSE_BODY_LUM_MAX = 0.69` and `REVERSE_SPREAD_MIN = 0.2`.
- Checked sets: `['DLR']`, matched on the set code's prefix before the first space
  (`'DLR 002/103'`).
- Runs only when all of these hold:
  - the named card is English
  - the card was not named as a guess
  - the options are exactly one Normal and one Reverse Holofoil printing
  - the frame came from the desktop scanner
- Otherwise behaviour stays as today.
- Run vitest through `npm test` (already `--maxWorkers=2`). Typecheck with `npm run typecheck:web`
  and `npm run typecheck:phone` separately; plain `typecheck` stops early.
- Work in the worktree `/var/tmp/revholo-wt` on branch `feat/reverse-holo-detection`. Other
  sessions commit in the main checkout.

## Review Focus

1. **A Normal card named Reverse Holofoil with no flag.** This is the stop-ship case. Task 5 adds a
   real-photo assertion that no Normal truth photo is named a sure Reverse Holofoil.
2. **A Japanese twin's image picked as the reference.** Expect no check. `draft()` takes `imageId`
   from the card's own images, which are shared by both English printings. Task 4 tests a
   Japanese-language draft and expects it unchanged.
3. **A card named by a guess rule** (`language-default`, `reprint`, etc.). Expect today's flag.
   Task 4 tests it.
4. **Version cues missing** (the card's orientation isn't known, so `version` is null). Expect
   today's flag. Task 4 tests it.
5. **Tilt read after a sure name.** Expect it to leave the row alone. Task 4 asserts that
   `readChoicesFor` returns null for the checked draft.

### Task 1: Shared body stats and the rule

**Files:**
- Create: `src/shared/scan/reverseHolo.ts`
- Modify: `src/shared/scan/thresholds.ts` (add the two constants)
- Test: `tests/main/scan-reverse-holo.test.ts`

**Interfaces:**
- Produces:
  - `interface BodyStats { ratio: number; spread: number }`. `ratio` is mean luma of BODY ÷ mean
    luma of ART. `spread` is the std ÷ mean of BODY luma.
  - `bodyStats(img: RgbaImage): BodyStats`. It shrinks to 200x292 (area average, alpha flattened
    on white) and measures.
  - `reverseVersion(photo: BodyStats, ref: BodyStats): 'Normal' | 'Reverse Holofoil'`. bodyLum is
    `photo.ratio / ref.ratio`, and spread is `photo.spread - ref.spread`.
  - `REVERSE_CHECKED_SETS: readonly string[] = ['DLR']`
  - `reverseChecked(setCode: string | null): boolean`

- [ ] **Step 1: Write failing tests**
  - `bodyStats` of a synthetic 842x1228 image whose ART region is luma 200 and BODY region is luma
    100 (uniform) gives `ratio` ≈ 0.5 (±0.01) and `spread` ≈ 0 (±0.01).
  - The same image at 400x584 gives the same stats (±0.01), so size doesn't matter.
  - A BODY of alternating 50/150 columns gives `spread` ≈ 0.5 (±0.05).
  - A fully transparent BODY reads as white (`ratio` = 255/200 ±0.02).
  - `reverseVersion`:
    - `{ratio:0.3,spread:0.1}` vs `{ratio:0.5,spread:0.1}` (bodyLum 0.6) → `'Reverse Holofoil'`
    - `{ratio:0.4,spread:0.1}` vs `{ratio:0.5,spread:0.1}` (0.8) → `'Normal'`
    - `{ratio:0.5,spread:0.35}` vs `{ratio:0.5,spread:0.1}` (spread 0.25) → `'Reverse Holofoil'`
    - bodyLum exactly 0.69 and spread exactly 0.20 → `'Normal'` (strict comparisons)
  - `reverseChecked('DLR 002/103')` is true. `reverseChecked('DRI 208/182')`,
    `reverseChecked('DLRX 1')` and `reverseChecked(null)` are false.
- [ ] **Step 2:** `npm test -- tests/main/scan-reverse-holo.test.ts`. Expected: FAIL, module not
  found.
- [ ] **Step 3:** Implement `src/shared/scan/reverseHolo.ts` and the two constants.
  - Area averaging is a box filter: each output pixel is the mean of the source pixels it covers,
    with fractional edges weighted.
  - Region bounds use `Math.round(fraction * size)`, as the spike did.
- [ ] **Step 4:** Run the test again. Expected: PASS.
- [ ] **Step 5: Spike parity check (not committed).**

  - Usage: `npx tsx scripts/scan/reverse-refs.ts <catalog.sqlite>`. The default is
